기본 반복 기간
반복 종료일을 비우면 시작일로부터 10년 뒤까지 반복합니다.
달력 지원 범위는 최대 2050년입니다.

반복 설정 변경
반복 주기·종료일을 바꾸면 선택한 일정부터 이후 반복 일정을 다시 구성합니다.
과거 기록은 유지됩니다.

개별 일정 수정
반복 일정의 제목·분류·색상·아이콘·메모 변경은 저장할 때 적용 범위를 선택할 수 있습니다.
전체 적용 시에도 각 회차의 날짜·음력 정보는 유지됩니다.
날짜 수정은 선택한 일정에만 적용됩니다.
반복 일정 삭제 시 현재 일정만 삭제할지, 전체 반복 일정을 삭제할지 선택할 수 있습니다.
반복 전환 시 이름·종류·날짜·기간이 같은 기존 회차는 중복 생성하지 않습니다.
일치하는 개별 기록이 하나면 재사용하고, 다른 일정은 유지합니다.

매월·음력 반복
매월 반복은 같은 양력·음력 날짜를 따르며, 없는 날짜는 해당 월의 말일에 등록합니다.
음력 매월 반복에는 윤달도 포함됩니다.
음력 매년 반복은 해당 윤달이 없는 해를 건너뛰며, 30일이 없는 해는 29일에 등록합니다.
